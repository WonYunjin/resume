# 이력서·자소서 도우미

채용 공고와 자소서 문항을 넣으면, 내 경험 중 맞는 것을 골라 글자 수에 맞춘 초안을 만들어 주는 도구입니다.
설치나 회원가입 없이 브라우저에서 바로 씁니다.

## 할 수 있는 것

- **내 정보·경험 정리**: 학력, 경력(근무 기간·총 경력 자동 계산), 자격증, 어학, 교육, 대외활동, 수상, 해외 경험, 병역, 증명사진, 경험 카드(상황·행동·결과)
- **이번 지원**: 회사명, 직무, 공고 요구 역량, 자소서 문항(붙여넣기·파일 첨부로 한꺼번에 넣기)
- **결과·복사**: 문항마다 맞는 경험을 골라 문항 유형별 초안을 만들고, 글자 수(공백 포함/제외)를 세고, 칸별로 복사
- **AI 부탁문**: 초안을 다듬어 달라는 요청문을 복사해서 AI 채팅에 붙여 넣기 (API 키 필요 없음)
- **이력서 파일**: 표준 이력서 양식의 한글 파일(.hwp / .hwpx) 또는 PDF로 저장. 블라인드 옵션(사진·학교명 빼기, 주소는 읍·면·동까지), 자기소개서·경력기술서는 새 페이지에서 시작
- **지원 기록**: 회사별 지원 내용, 진행 상태, 메모 보관

## 내 정보는 어디에 저장되나요?

입력한 내용은 **내 브라우저 안(localStorage)에만** 저장되고, 어떤 서버로도 보내지지 않습니다.
다른 사람은 내 내용을 볼 수 없습니다. 다른 컴퓨터·브라우저로 옮길 때는 화면 오른쪽 위의 **JSON 내보내기 → JSON 불러오기**를 쓰세요.
브라우저의 사이트 데이터를 지우면 내용도 지워지니, 가끔 JSON으로 백업해 두세요.

## 참고

- 최신 엣지나 크롬을 권장합니다.
- PDF 첨부를 읽을 때만 인터넷에서 PDF 읽기 도구(pdf.js)를 불러옵니다.
- 만든 한글 파일은 한글 2014 이상에서 열어 확인하세요.
